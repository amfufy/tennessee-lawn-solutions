# Tennessee Lawn Solutions — Landing Page

Static one-page site for Tennessee Lawn Solutions LLC (Lewisburg, TN). No build step.

## Publish on GitHub Pages
1. Create a new public repo and upload everything in this folder (index.html, images/, README.md).
2. Repo Settings → Pages → Source: "Deploy from a branch" → Branch: main, folder: / (root) → Save.
3. The site goes live at https://<your-username>.github.io/<repo-name>/ within a minute or two.

## Estimate form
Requests are emailed through FormSubmit.co (free). Change `FORM_EMAIL` near the bottom of index.html
to the address that should receive requests. The first submission triggers a one-time activation
email to that address; click the link once and every request after that arrives normally.
